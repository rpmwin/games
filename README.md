# games

Mini browser games built for fun. Each game is a standalone React + Vite app.

## Games

| Game | Description |
|------|-------------|
| `Tic-Tac-Toe` | Classic 3×3 |
| `Super-Tic-Tac-Toe` | Each cell is a full Tic-Tac-Toe board |
| `4inrow` | Connect Four |
| `HangMan` | Word guessing game |
| `sudokuSolver` | Sudoku board with solver |

## Run any game

```bash
cd <game-folder>
npm install
npm run dev
```
